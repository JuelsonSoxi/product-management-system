⚡ QUICK START (30 segundos):

Option 1 - Automático (Recomendado):
  $ chmod +x setup.sh
  $ ./setup.sh
  
  Depois abre 2 terminais:
  Terminal 1: cd backend && php artisan serve
  Terminal 2: cd frontend && npm run dev

Option 2 - Manual:

  Backend:
    $ cd backend
    $ composer install
    $ cp .env.example .env
    $ php artisan key:generate
    $ php artisan migrate:fresh --seed
    $ php artisan serve

  Frontend (outro terminal):
    $ cd frontend
    $ npm install
    $ cp .env.example .env
    $ npm run dev
